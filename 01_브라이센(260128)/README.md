# Chapter 01. 브라이센(260128)

이 폴더에는 브라이센에서 수행한 YourLifeLog 앱 개발 프로젝트의 플랫폼별 결과 보고서와 API 명세서가 보관되어 있습니다.

## 상세 내용

### Android
- **가천대학교 라이프로그 전송 App 개발 보고서.pdf**: Android 앱의 전반적인 개발 과정, 주요 기능 구현 방식, 테스트 결과가 기술되어 있습니다.
- **가천대학교 라이프로그 전송 App Api 명세서.pdf**: Android 앱에서 사용하는 서버 통신 규격 및 API 명세입니다.
- **Android Project 링크** : https://gitlab.chemainet.com/winform/yourlifelog

### iOS
- **가천대학교_정밀영양_라이프로그_iOS_App_개발보고서.pdf**: iOS 앱의 개발 아키텍처(MVVM), SwiftUI 구현 상세, HealthKit 연동 방식이 기술되어 있습니다.
- **TestFlight_배포_가이드.pdf**: iOS 앱 테스트를 위한 TestFlight 배포 절차 안내입니다.
- **TestFlight_배포_권장_사유.txt**: TestFlight 배포를 권장하는 필요한 기술적/운영적 근거입니다.
- **iOS Project 링크** : https://gitlab.chemainet.com/winform/yourlifelog_ios
