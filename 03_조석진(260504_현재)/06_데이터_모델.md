# 6. 데이터 모델 문서 (Data Model)

본 문서는 앱 내에서 사용되는 주요 데이터 모델 및 저장 구조를 정의합니다.

## 1. 도메인 모델 (Domain Models)

### DailyHealthData (공통)
앱 내에서 다루는 표준 건강 데이터 요약 구조입니다.
- `date`: 날짜 (Date)
- `stepCount`: 걸음 수 (Double?)
- `minHeartRate`: 최소 심박수 (Double?)
- `maxHeartRate`: 최대 심박수 (Double?)
- `distance`: 이동 거리 (Double?, km)
- `calories`: 소모 칼로리 (Double?, kcal)
- `weight`: 체중 (Double?, kg)
- `height`: 신장 (Double?, cm)
- `sleepTime`: 수면 시간 (Double?, 분)
- `exerciseTime`: 운동 시간 (Double?, 분)

## 2. 데이터 전송 객체 (DTO)

### Login API (Payload)
```swift
LoginRequest {
    name: String
    number: String
}

LoginResponse {
    accessToken: String
    ptcseq: Int
}
```

### HealthSyncRequest (Payload)
```swift
HealthSyncRequest {
    ptcseq: Int
    deviceModel: String
    syncTime: Int64
    dailyRecords: [DailyRecord]
}

DailyRecord {
    date: String
    healthRecords: [HealthRecord]
}

HealthRecord {
    type: String
    value: Double?
    minValue: Double?
    maxValue: Double?
    unit: String
    startTime: Int64
    endTime: Int64
}
```

## 3. 로컬 저장소 스키마

### iOS (UserDefaults / Keychain)
- **Keychain:** `accessToken` (보안 저장)
- **UserDefaults:**
  - `ptcSeq`: 참여자 고유 번호
  - `researchConsentAccepted`: 연구 동의 여부 (Bool)
  - `testStartDate`: 연구 시작일

### Android (DataStore / EncryptedSharedPreferences)
- **EncryptedSharedPreferences:** `ACCESS_TOKEN` (보안 저장)
- **DataStore:**
  - `PTC_SEQ`: 참여자 고유 번호
  - `TEST_START_DATE`: 연구 시작일
  - `IS_LOGGED_IN`: 로그인 상태 (Bool)
