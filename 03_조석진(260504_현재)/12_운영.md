# 12. 운영 문서 (Production Operations)

본 문서는 앱 출시 후 운영 및 장애 대응을 위한 가이드입니다.

## 1. 장애 대응 방법
- **긴급 패치 절차:** 치명적 결함 발견 시 App Store 및 Play Store의 긴급 심사/배포 절차를 통해 업데이트를 진행합니다.

## 2. 모니터링 및 알림
- **에러 모니터링:** 현재 외부 도구(Sentry 등) 미도입 상태로, 향후 도입 검토 권장.
- **서버 로그:** 연구 서버 측 API 호출 로그를 통해 업로드 실패 여부 모니터링.

## 3. Remote Config 및 Feature Flag
- 현재 구현된 원격 설정 기능은 없으며, 모든 정책은 앱 내 빌드 설정에 따릅니다.

## 4. 고객 지원 (연구 참여자 대응)
- 권한 설정 관련 문의 시 시스템 설정의 '건강' 앱 권한 확인 안내.
- 로그인 실패 시 연구 서버에 등록된 대상자 명단 대조 필요.
