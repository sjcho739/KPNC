# 3. 기능 명세서 (Feature Specification)

본 문서는 YourLifeLog (KPNC) 앱의 주요 기능과 각 플랫폼별 구현 상태를 정의합니다.

## 1. 연구 동의 (IRB Consent)
- **기능 설명:** 사용자가 건강 데이터 수집 및 연구 참여에 대한 약관을 검토하고 동의함.
- **진입 조건:** 앱 최초 실행 시 또는 동의 데이터가 로컬에 없는 경우.
- **구현 상태:**
  - **iOS:** `ResearchConsentView`가 구현되어 있으며, 앱 시작 시 `fullScreenCover`로 표시됨. `SessionManager`를 통해 동의 여부를 저장.
  - **Android:** **미지원** (코드베이스 내 관련 UI 및 로직 미확인).

## 2. 사용자 인증 (Login)
- **기능 설명:** 연구 대상자의 이름과 전화번호를 사용하여 서버에 인증.
- **입력값:** 성명(`name`), 전화번호(`number`).
- **구현 방식:**
  - **iOS:** 전용 `LoginView` 및 `LoginViewModel`을 통해 수행. 성공 시 `AccessToken` 및 `ptcSeq` 저장.
  - **Android:** `HomeScreen` 진입 시 `LoginDialog`를 통해 수행. 성공 시 `DataStore`에 토큰 및 상태 저장.
- **예외 처리:** 서버 404 에러 시 "등록되지 않은 사용자" 안내.

## 3. 테스트 시작일 설정 (Test Start Date)
- **기능 설명:** 연구 데이터 수집의 기준이 되는 시작 날짜를 설정.
- **동작 규칙:** 로그인 성공 후 시작일 정보가 없는 경우 날짜 선택창을 강제로 표시.
- **구현 상태:** 양 플랫폼 모두 지원. 설정된 날짜는 건강 데이터 조회 시 시작 지점으로 사용됨.

## 4. 건강 데이터 수집 및 동기화 (Health Data Sync)
- **기능 설명:** 단말기의 건강 데이터 저장소로부터 데이터를 읽어와 서버로 업로드.
- **수집 항목:**
  - 걸음 수 (Steps)
  - 심박수 (Heart Rate - 최소/최대)
  - 활동 칼로리 (Calories)
  - 이동 거리 (Distance)
  - 수면 시간 (Sleep Time)
  - 체중 및 신장 (Weight/Height)
  - 운동 시간 (Exercise Time)
- **업로드 방식:** 일별 요약 데이터(`DailyHealthData`)를 생성하여 `POST /health/sync.do` 호출.
- **플랫폼 차이:**
  - **iOS:** HealthKit 프레임워크 사용.
  - **Android:** Health Connect(구 Google Fit 대체) 사용.

## 5. 대시보드 및 홈 (Home Dashboard)
- **기능 설명:** 현재 수집된 데이터의 요약 정보를 화면에 표시하고 동기화 상태를 관리.
- **주요 UI 컴포넌트:**
  - 일별 데이터 리스트.
  - 동기화 버튼 (수동 트리거).
  - 계정/설정 진입 아이콘.

## 6. 계정 관리 및 로그아웃
- **기능 설명:** 로그인된 사용자 정보 확인 및 로컬 데이터(토큰 등) 삭제 후 초기화.
- **구현 방식:**
  - **iOS:** 별도의 프로필 뷰 또는 설정 메뉴.
  - **Android:** `AccountDialog` 및 `LogoutConfirmDialog` 활용.
