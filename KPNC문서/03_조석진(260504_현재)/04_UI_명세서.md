# 4. 화면 정의서 (UI Specification)

## 화면 맵 (Screen Map)

### iOS
1. **LaunchScreen:** 앱 로딩 화면.
2. **ResearchConsentView:** (최초 1회) 연구 동의 약관 화면.
3. **LoginView:** 이름/전화번호 입력 로그인 화면.
4. **HomeView:** 일별 건강 데이터 목록 및 동기화 버튼이 있는 메인 화면.
5. **SettingsView:** 사용자 정보 확인 및 로그아웃 버튼.

### Android
1. **Launch Screen:** 앱 아이콘 및 테마 로딩.
2. **HomeScreen (Main):** 메인 대시보드 화면.
   - **LoginDialog:** 로그인 필요 시 표시되는 팝업.
   - **TestStartDatePickerDialog:** 날짜 선택 팝업.
   - **AccountDialog:** 사용자 정보 확인 팝업.
   - **LogoutConfirmDialog:** 로그아웃 확인 팝업.
3. **AnalyticsScreen (Future):** 데이터 통계 화면 (폴더 구조상 존재 확인).

## 주요 이동 플로우
1. **초기 진입:** Launch Screen -> (iOS: Consent) -> Home.
2. **로그인 필요 시:** Home -> Login (Dialog/View).
3. **날짜 미설정 시:** Login 성공 -> Start Date Picker.
4. **정상 상태:** Home (데이터 목록 표시).

## UI 컴포넌트 설명 (핵심)
- **Health Data Card:** 걸음 수, 심박수 등 항목별 아이콘과 수치 표시.
- **Sync Button:** 서버 전송 상태를 애니메이션으로 표시하거나 트리거.
- **Status Indicator:** 데이터가 서버에 업로드되었는지 여부를 체크마크 등으로 표시.

## 예외 상태 처리
- **로딩 상태:** 데이터 조회 또는 서버 통신 시 `ProgressView`(iOS) 또는 `CircularProgressIndicator`(Android) 표시.
- **빈 상태 (Empty State):** 수집된 건강 데이터가 없는 경우 "데이터가 없습니다" 메시지 표시.
- **에러 상태:** 네트워크 단절 또는 권한 거부 시 경고 알림(Alert/Snackbar) 표시.
