# 8. 개발 환경 세팅 문서 (Development Environment)

신규 개발자가 프로젝트를 시작하기 위한 환경 설정 가이드입니다.

## 필수 도구 및 버전

| 구분 | iOS | Android |
| :--- | :--- | :--- |
| **OS** | macOS (Sequoia 이상 권장) | Windows / macOS / Linux |
| **IDE** | Xcode 16.0+ | Android Studio Ladybug+ |
| **Language** | Swift 5.0+ | Kotlin 2.0+ |
| **SDK** | iOS 16.0+ Deployment Target | Android SDK 28 (Pie) ~ 36 |

## 프로젝트 실행 방법

### iOS
1. `GachonHealthSyncApp.xcodeproj` 파일을 Xcode로 엽니다.
2. 실기기(HealthKit 테스트용)를 연결합니다. (시뮬레이터는 일부 데이터 수집 불가)
3. `Run` (Cmd + R)을 수행하여 앱을 빌드하고 실행합니다.

### Android
1. Android Studio에서 `Android/yourlifelog/gacheon/gacheon` 폴더를 프로젝트로 엽니다.
2. Gradle 싱크가 완료될 때까지 기다립니다.
3. Health Connect가 설치된 실기기 또는 에뮬레이터에서 실행합니다.

## 주요 설정 및 키 관리
- **인증키:** 서버 Base URL 및 보안 토큰은 코드 내 `APIEndpoint` 및 로컬 보안 저장소에서 관리됩니다.

## 목표
- 환경 설정 후 30분 이내에 실기기에서 앱 실행 및 Health 데이터 접근 권한 요청 확인.
